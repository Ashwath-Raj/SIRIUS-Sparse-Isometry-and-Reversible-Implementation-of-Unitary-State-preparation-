# Phase 9.1 design release

The committed design documents are:

- `docs/PHASE9_1_BENCHMARK_SYSTEM_DESIGN.md` — full benchmark architecture and experimental protocol.
- `docs/PHASE9_1_REPRODUCIBILITY_PROTOCOL.md` — run identity, timing boundaries, statistical treatment and integrity rules.
- `docs/PHASE9_1_DGX_ACCESS_BRIEF.md` — institutional access request rationale, pilot plan and safeguards.
- `docs/PROJECT_ARCHITECTURE.md` — module and execution boundary map.
- `benchmarking/config/phase9_1_benchmark_plan.json` — machine-readable sweeps and execution settings.
- `benchmarking/metric_catalog.json` and `benchmarking/schemas/` — metric and result data contracts.

The phase intentionally does not run benchmarks or create numeric result files. See `benchmarking/README.md` for the 9.2 execution contract.
